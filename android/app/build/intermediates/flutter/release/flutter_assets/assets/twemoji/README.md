Twemoji assets (curated subset)

These PNG images are a small curated subset of Twitter's Twemoji project, included to provide reliable emoji image fallbacks on platforms or browsers where native glyphs are missing.

Source: https://github.com/twitter/twemoji

Important: Please verify the Twemoji license and attribution requirements for your distribution; this README is informational only and not a legal statement of license compliance.

If you decide to add or update images here, run:
  tools/download_twemoji_pngs.ps1

and ensure CI checks (/.github/workflows/verify_twemoji_assets.yml) continue to pass.
